# WebTraSua - Website Quản Lý & Đặt Trà Sữa Online

Hệ thống website hỗ trợ đặt hàng, quản lý người dùng, xử lý đơn hàng và thanh toán trực tuyến.

## Công nghệ sử dụng
- **Backend:** Java Spring Boot, Maven
- **Frontend:** Thymeleaf, HTML5/CSS3, JavaScript
- **Cơ sở dữ liệu:** MySQL (`webtrasua.sql`)
